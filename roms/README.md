# Your games go here

No game ROMs come with this repository, and none may be committed to it.
Put NES games **you own** in this folder, for example ROMs you dumped from your
own cartridges, or homebrew games whose authors share them freely.

Accepted: `.nes` files, or `.zip` files with a `.nes` inside. Everything here
except this README is ignored by git.

You can also skip this folder: start the dashboard and press **+ Add game** to
pick a ROM from anywhere on your PC (it is copied here).

Another folder works too: `--rom-dir "D:\my games"` or set `FLY_ROMS`.
